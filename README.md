**Векторный конструктор шрифтов прямо в браузере.** Рисуй буквы, настраивай метрики, экспортируй настоящий `.ttf` — без серверов, аккаунтов и платных подписок.

🔗 **Открыть сайт:** [levkryzankov-spec.github.io/font_creator](https://levkryzankov-spec.github.io/font_creator/)

---

## ✨ Возможности

- ✏️ **Рисование глифов** — мышь, тачпад или палец на телефоне
- ◉ **Редактор точек** — перетаскивание узлов, отражение, поворот, сглаживание
- 🌍 **Мультиязычность** — латиница, кириллица, хирагана, катакана, цифры, пунктуация
- 📚 **Библиотеки символов** — создавай несколько наборов, сливай, дублируй, импортируй из JSON
- ⚙️ **Мета-редактор TTF** — имя шрифта, автор, лицензия, версия, copyright
- 📐 **Метрики глифа** — advance width, LSB, RSB, направляющие baseline / x-height / cap-height
- 📤 **Экспорт в TTF** — настоящий валидный файл, работает в Word, Figma, Photoshop
- 💾 **Автосохранение** — всё хранится в localStorage браузера
- 🎨 **Один HTML-файл** — без сборки, без npm, без зависимостей
- 🌐 **Работает офлайн** — после первой загрузки (кроме генератора TTF)

## 🚀 Как пользоваться

### 1. Открой сайт
Перейди по ссылке выше. Или скачай `index.html` и открой локально в браузере.

### 2. Нарисуй букву
- Выбери символ в левой панели (например, «A»)
- Рисуй линии на холсте — тяни мышью или пальцем
- ПКМ по линии — удалить её
- `Ctrl+Z` / `Ctrl+Y` — отмена / возврат

### 3. Настрой метрики
- **Advance width** — ширина символа (сдвиг курсора после буквы)
- **LSB / RSB** — отступы слева и справа
- Включи **прилипание к сетке** для точного выравнивания

### 4. Режим точек (для точной правки)
- Нажми `Пробел` или кнопку **«◉ Точки»**
- Кликай по узлам, тяни их, `Shift+клик` — множественное выделение
- **↔ H / ↕ V** — отразить глиф
- **⟳ 90°** — повернуть
- **〜 Сгладить** — сгладить выбранные узлы

### 5. Заполни метаданные
- Кнопка **«⚙ Мета»** — имя шрифта, автор, лицензия, версия
- Эти данные попадут в TTF и будут видны в свойствах шрифта

### 6. Скачай TTF
- Кнопка **«⬇ TTF»** — сохраняет `MyFont.ttf`
- Установи его в систему: ПКМ → «Установить» (Windows) или двойной клик (macOS)
- Открой Word / Figma и выбери свой шрифт

## 🎯 Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Пробел` | Переключить режим рисовать / точки |
| `Ctrl + Z` | Отменить |
| `Ctrl + Y` | Вернуть |
| `Ctrl + C` | Копировать глиф (в режиме точек) |
| `Ctrl + V` | Вставить глиф (в режиме точек) |
| `ПКМ` | Удалить линию / точку |

## 📚 Библиотеки символов

- **＋ Новая** — создать пустой набор со своим названием
- **✎ Имя** — переименовать
- **⧉ Дубль** — дублировать библиотеку со всеми глифами
- **⊕ Слить** — добавить символы из другой библиотеки
- **✕ Удалить** — удалить символы (только из «Свои»)
- **📁 Импорт** — загрузить библиотеку из JSON
- **💾 Экспорт** — сохранить библиотеку в JSON со всеми глифами

## 🌐 Встроенные наборы

- **Латиница** A–Z, a–z (52 символа)
- **Кириллица** А–Я, а–я (66 символов, включая Ё/ё)
- **Цифры** 0–9
- **Пунктуация** `. , ! ? ; : ' " ( ) [ ] { } « » — – - + * / = @ # $ % & № § ¶`
- **Хирагана** あいうえお... (70 символов с вариациями)
- **Катакана** アイウエオ... (70 символов с вариациями)
- **Свои** — собственные символы (эмодзи, иероглифы, знаки)

## ⚠️ Известные ограничения

- **Пересекающиеся штрихи** в TTF остаются отдельными контурами — на пересечениях может быть «дырка» заливки
- **Только прямые линии** — кривые Безье пока не поддерживаются
- **localStorage** привязан к браузеру — при очистке кэша данные удалятся (делай экспорт в JSON)
- **CDN opentype.js** — если провайдер блокирует jsdelivr, TTF не сгенерируется

## 🛠 Технологии

- Чистый **HTML + CSS + JavaScript** — никаких фреймворков
- **[opentype.js](https://opentype.js.org/)** — генерация TTF-файлов
- **Canvas 2D** — рисование и предпросмотр
- **localStorage** — сохранение прогресса
